# AI-tool usage declaration

AI assistance was used to support implementation, code review, debugging, documentation structure and test inspection for the L2 extension.

The supplied L1/L2 datasets were processed locally in the project environment. No supplied dataset was intentionally sent to an external model/API by the application.

The final implementation, decision rules, outputs, privacy masking, benchmark measurements and limitations were inspected against the supplied assignment data. No mandatory test-case result was hardcoded into the production pipeline.
